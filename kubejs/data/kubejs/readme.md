# data/kubejs/

Custom datapack content for Star Technology.

## Structure

| Path                                         | Description                                                                                                                                                        |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`damage_type/`](damage_type/)               | Custom damage type definitions. Includes `abyssal_pull.json`, `heat_exhaustion.json`, and `radiation.json` — used by dimensional hazard and environmental systems. |
| [`loot_tables/chests/`](loot_tables/chests/) | Custom chest loot tables. `components.json` defines drops for component-containing structures.                                                                     |
| [`structures/obelisk/`](structures/obelisk/) | NBT structure files for custom obelisk structures placed in the world.                                                                                             |
