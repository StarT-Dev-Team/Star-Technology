# config/

KubeJS configuration directory — the only directory accessible to scripts outside the world folder.

## Files

| File                                     | Description                                                                    |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| [`client.properties`](client.properties) | Client-side KubeJS config options.                                             |
| [`common.properties`](common.properties) | Shared (server+client) KubeJS config options.                                  |
| [`item_hiding.json`](item_hiding.json)   | Item hiding configuration used by `server_scripts/item_hiding.js` for JEI/EMI. |
| [`packicon.png`](packicon.png)           | Modpack icon image.                                                            |
