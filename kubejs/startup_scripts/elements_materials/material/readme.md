# startup_scripts/elements_materials/material/

Registers compound GregTech materials and related material helpers.

## Structure

| Path                                                                         | Description                                                                    |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [`helpers.js`](helpers.js)                                                   | Shared helpers for building material definitions and applying common settings. |
| [`base_materials.js`](base_materials.js)                                     | Core material definitions used as building blocks for later materials.         |
| [`base_chemicals.js`](base_chemicals.js)                                     | Chemical and reagent-style material registrations.                             |
| [`element_materials.js`](element_materials.js)                               | Materials derived from or associated with element definitions.                 |
| [`chem_groups.js`](chem_groups.js)                                           | Chemical groups as materials.                                                  |
| [`casing_materials.js`](casing_materials.js)                                 | Materials that make up casings.                                                |
| [`combustion_fuels_and_oxidizers.js`](combustion_fuels_and_oxidizers.js)     | Fuel and oxidizer materials.                                                   |
| [`infernal_concentrates.js`](infernal_concentrates.js)                       | Infernal concentrates for the Hellforge                                        |
| [`ores_and_magmas.js`](ores_and_magmas.js)                                   | Ore and magma material definitions.                                            |
| [`plasmas.js`](plasmas.js)                                                   | Plasma-related material definitions.                                           |
| [`solders.js`](solders.js)                                                   | Solder alloy materials.                                                        |
| [`superconductors.js`](superconductors.js)                                   | Superconductor material registrations.                                         |
| [`ae2_materials.js`](ae2_materials.js)                                       | AE2-related materials.                                                         |
| [`agricultural_materials.js`](agricultural_materials.js)                     | Agricultural or crop-related material definitions.                             |
| [`misc.js`](misc.js)                                                         | Miscellaneous material registrations.                                          |
| [`placeholders.js`](placeholders.js)                                         | Placeholder material entries.                                                  |
| [`resource_gen.js`](resource_gen.js)                                         | Resource-generation-related material definitions.                              |
| [`deprecated.js`](deprecated.js)                                             | Legacy or deprecated material definitions.                                     |
| [`abydos_alloys.js`](abydos_alloys.js)                                       | Abydos-region alloy material registrations.                                    |
| [`netherite_alloys_and_derivatives.js`](netherite_alloys_and_derivatives.js) | Netherite-based alloy and derivative materials.                                |
| [`nuclear_rods.js`](nuclear_rods.js)                                         | Nuclear rod or fuel-related material definitions.                              |
| [`iconsets.js`](iconsets.js)                                                 | Material iconset definitions.                                                  |
| [`modifications.js`](modifications.js)                                       | Patches or adjustments for existing material definitions.                      |
| [`lines/`](lines/)                                                           | Additional material scripts grouped by production line or theme.               |
