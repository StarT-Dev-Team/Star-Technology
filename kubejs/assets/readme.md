# assets/

Resource-pack layer for KubeJS and mod asset overrides.  
Structured identically to a standard Minecraft resource pack (`assets/<namespace>/`).

## Namespaces

| Namespace                                            | Description                                                                                      |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [`kubejs/`](kubejs/)                                 | Textures, models, blockstates, and lang files for all custom KubeJS-registered blocks and items. |
| [`gtceu/`](gtceu/)                                   | Texture and model overrides for GregTech CEu machines, items, and recipe type icons.             |
| [`colossalchests/`](colossalchests/)                 | Lang overrides for Colossal Chests.                                                              |
| [`create_new_age/`](create_new_age/)                 | Texture and lang overrides for Create: New Age.                                                  |
| [`createdieselgenerators/`](createdieselgenerators/) | Lang overrides for Create Diesel Generators.                                                     |
| [`emi/`](emi/)                                       | Lang overrides for EMI.                                                                          |
| [`ftbquestlocalizer/`](ftbquestlocalizer/)           | Lang files used by the FTB Quest Localizer tool.                                                 |
| [`megacells/`](megacells/)                           | Lang overrides for Mega Cells (AE2 addon).                                                       |
| [`minecraft/`](minecraft/)                           | Lang overrides for vanilla Minecraft.                                                            |
| [`projectred/`](projectred/)                         | Lang overrides for ProjectRed.                                                                   |
| [`sgjourney/`](sgjourney/)                           | Lang and texture overrides for SG Journey.                                                       |
| [`xtones/`](xtones/)                                 | Lang overrides for Xtones.                                                                       |
| [`xycraft_world/`](xycraft_world/)                   | Lang overrides for XyCraft World.                                                                |
