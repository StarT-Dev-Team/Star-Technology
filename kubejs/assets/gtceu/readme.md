# assets/gtceu/

GregTech CEu asset overrides — textures, item/block models, machine UI textures, and recipe type icons.

## Structure

| Path | Description |
|---|---|
| [`lang/`](lang/) | Translation overrides for GTCEu lang (EN, JA, KO, RU). |
| [`models/item/`](models/item/) | Item model overrides for GTCEu items. |
| [`textures/block/`](textures/block/) | Block texture overrides (machine casings, overlays, etc.). |
| [`textures/item/`](textures/item/) | Item texture overrides (materials, components, etc.). |
| [`ui/machine/`](ui/machine/) & [`ui/recipe_type/`](ui/recipe_type/) | Machine GUIs. |
