# assets/kubejs/

Custom assets for all KubeJS-registered content in Star Technology.

## Structure

| Path | Description |
|---|---|
| [`blockstates/`](blockstates/) | Blockstate JSON files for custom blocks (e.g. coil block variants). |
| [`lang/`](lang/) | Translation files for KubeJS content in English, Japanese, Korean, and Russian. |
| [`models/armor/`](models/armor/) | Armor model definitions for custom armor pieces. |
| [`models/block/`](models/block/) | Block model definitions for custom blocks. |
| [`models/item/`](models/item/) | Item model definitions for custom items (tools, components, etc.). |
| [`textures/block/`](textures/block/) | Block textures for custom blocks. |
| [`textures/item/`](textures/item/) | Item textures for custom items. |
| [`textures/mob_effect/`](textures/mob_effect/) | Icons for custom potion/mob effects. |
| [`textures/models/`](textures/models/) | Texture sheets used by custom entity or armor models. |
| [`textures/quests/`](textures/quests/) | Images used in FTB Quests. |
