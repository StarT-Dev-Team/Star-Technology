# client_scripts/hardmode/

Client scripts that only run in **hardmode** packmode.

## Files

| File | Description |
|---|---|
| [`info.js`](info.js) | JEI information entries explaining how to obtain basic early-game resources (sticks, bark, fibers, flint shards, water bowls, etc.) in hardmode where vanilla recipes are locked. |
| [`jei.js`](jei.js) | Additional JEI recipe viewer tweaks specific to hardmode. |
| [`renaming_items.js`](renaming_items.js) | Renames certain items in hardmode to better reflect their function or gating within the hardmode progression. |
