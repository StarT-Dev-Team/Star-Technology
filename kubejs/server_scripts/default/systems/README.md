| [`fission/nuclear_reactor.js`](fission/nuclear_reactor.js) | Nuclear reactor multiblock operational recipes (heat output, steam generation). |

| [`resource_generation/pebbling.js`](resource_generation/pebbling.js) | Pebble-to-resource conversion recipes. |
| [`resource_generation/void_drill_line/clusters.js`](resource_generation/void_drill_line/clusters.js) | Void drill cluster output recipes. |
| [`resource_generation/void_drill_line/crystallisation.js`](resource_generation/void_drill_line/crystallisation.js) | Crystal growth recipes from void drill outputs. |
| [`resource_generation/void_drill_line/minerals.js`](resource_generation/void_drill_line/minerals.js) | Mineral extraction recipes from void drill processing. |
