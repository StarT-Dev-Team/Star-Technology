# server_scripts/default/additions/

Recipe additions exclusive to default packmode.

## Files & Folders

| Path | Description |
|---|---|
| [`circuit_etching.js`](circuit_etching.js) | Recipes for circuit etching (UV/laser etching of circuit boards). |
| [`superconductors.js`](superconductors.js) | Superconductor wire and coil recipes. |
| [`machines_and_parts/`](machines_and_parts/) | Machine crafting recipes — coils, converters, hatches/busses, intermediate and large multiblocks, single blocks. |
| [`machines_and_parts/tiered_machines/`](machines_and_parts/tiered_machines/) | Tiered machine recipes: IO hatches, large energy hatches, modular power hatches, parallel hatches, single-block tiers, storage blocks, and transformers. |
| [`progression/early_game/`](progression/early_game/) | Early-game recipe additions before GT machines are available (alloys & tools, backports from later versions, barrels, blast furnaces, caskets, composters, miscellaneous QoL, sieving). |
| [`progression/lines/dimensional_air.js`](progression/lines/dimensional_air.js) | Dimensional Air processing chain (default packmode only). |
