# server_scripts/default/

Recipe scripts that run only in **default** packmode.

## Structure

| Folder | Description |
|---|---|
| [`additions/`](additions/) | Default-mode recipe additions (machines, early game, superconductors, etc.). |
| [`modifications/`](modifications/) | Default-mode targeted recipe modifications (Create, Pipez, item collectors). |
| [`systems/`](systems/) | Default-mode gameplay systems (fission reactors, ore factory processing, resource generation). |
