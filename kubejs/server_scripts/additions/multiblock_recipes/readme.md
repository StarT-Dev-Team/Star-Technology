Recipes that run inside Star Technology's custom multiblock machines.

| [`multiblock_barrels.js`](multiblock_barrels.js) | Recipes for tiered barrel multiblocks (e.g. Industrial Barrel). |
| [`nether_multis.js`](nether_multis.js) | Recipes for Nether multiblocks. |
| [`old_to_new_fusion_temp.js`](old_to_new_fusion_temp.js) | Temporary migration recipes converting old fusion casing formats to the new system. To be removed in Theta 2. |
| [`pre_gate_multis.js`](pre_gate_multis.js) | Recipes for pre-Stargate multiblocks (machines available before first gate activation). |
| [`riftic_multis.js`](riftic_multis.js) | Recipes for Riftic multiblocks. |
| [`vacuum_chemical_reactor.js`](vacuum_chemical_reactor.js) | Recipes for the Vacuum Chemical Reaction Chamber multiblocks. |
