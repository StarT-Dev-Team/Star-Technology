# server_scripts/hardmode/utils/

Server-side utility scripts exclusive to hardmode packmode.

## Files

| File | Description |
|---|---|
| [`tag_changes.js`](tag_changes.js) | Hardmode tag additions and removals (item/block/fluid tags that differ from default mode). |
| [`loot_tables.js`](loot_tables.js) | Hardmode loot table modifications — adjusts drops from blocks and entities for hardmode resource scarcity. |

## [events/](events/)

| File | Description |
|---|---|
| [`on_load.js`](events/on_load.js) | Server load event hooks specific to hardmode — runs initialization logic when the server starts (e.g. validating hardmode configuration). |
