# server_scripts/hardmode/progression/

Crafting and progression recipes exclusive to hardmode packmode.

## Root files

| File | Description |
|---|---|
| [`misc.js`](misc.js) | Miscellaneous hardmode progression recipes that don't fit a specific category. |

## Subfolders

| Folder | Description |
|---|---|
| [`general_progression/`](general_progression/) | Core progression recipes: casings, circuits, components, and machines — all harder to obtain than in default mode. |
| [`pre_lv/`](pre_lv/) | Pre-LV (before first electric machine) progression — Create mod age recipes required to bootstrap GT in hardmode. |
