| [`laserio.js`](laserio.js)                       | Modifies LaserIO recipes (nodes, cards, connectors).                  |
| [`modular_routers.js`](modular_routers.js)       | Modifies Modular Routers recipes (modules, upgrades, routers).        |
| [`pipez.js`](pipez.js)                           | Modifies Pipez pipe recipes.                                          |
| [`project_red.js`](project_red.js)               | Modifies ProjectRed logic gate and cable recipes.                     |
| [`thermal.js`](thermal.js)                       | Modifies Thermal Series machine and augment recipes.                  |
