# server_scripts/common/modifications/

Targeted modifications to existing mod recipes, shared by all packmodes.

## Files

| File | Description |
|---|---|
| [`create_hypertubes.js`](create_hypertubes.js) | Adjusts Create Hypertube recipes. |
| [`exnihilo.js`](exnihilo.js) | Modifies Ex Nihilo Sequentia recipes (sieve meshes, crucibles, etc.). |
| [`flux_networks.js`](flux_networks.js) | Modifies Flux Networks recipes. |
| [`functional_storage.js`](functional_storage.js) | Modifies Functional Storage (drawer) recipes. |
| [`general.js`](general.js) | Miscellaneous cross-mod recipe tweaks. |
| [`project_red.js`](project_red.js) | Modifies ProjectRed logic gate and cable recipes. |
| [`thermal.js`](thermal.js) | Modifies Thermal Series machine and augment recipes. |
| [`travel_anchors.js`](travel_anchors.js) | Modifies Travel Anchors recipes. |
| [`xycraft.js`](xycraft.js) | Modifies XyCraft World recipes. |

## [ae2/](ae2/) subfolder

| File | Description |
|---|---|
| [`ae2_qol.js`](ae2/ae2_qol.js) | Quality-of-life AE2 recipe tweaks. |
| [`components.js`](ae2/components.js) | Modifies AE2 component (processors, engineering processors, etc.) recipes. |
| [`gt_compat.js`](ae2/gt_compat.js) | GT↔AE2 compatibility recipe adjustments. |
| [`machinery.js`](ae2/machinery.js) | Modifies AE2 machine (ME Controller, drives, cables) recipes. |
| [`removals.js`](ae2/removals.js) | Removes conflicting AE2 recipes replaced by Star Technology. |
| [`storage_cells.js`](ae2/storage_cells.js) | Modifies AE2 storage cell recipes. |
| [`storage_components.js`](ae2/storage_components.js) | Modifies AE2 storage component recipes. |
