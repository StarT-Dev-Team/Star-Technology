<h1 style="text-align: center;">What is Star Technology?</h1>

Star Technology was one of the first **GregTech CEu Modern** modpacks, originally built for **Minecraft 1.19.2** and now fully updated to **1.20.1**. While still in active development, the pack is fully playable through **Draconic Stargate (UIV)**, with the content being refined with each update.

This is **not** a beginner-friendly modpack (as in for players new to modded Minecraft) — but we're continually working to make it more approachable for new players.
